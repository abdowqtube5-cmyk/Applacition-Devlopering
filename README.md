# 🌿 LustreHair | Premium Hair Oil Store 

LustreHair is a sophisticated e-commerce mobile application built with **Flutter**. It offers a seamless shopping experience for luxury hair oils, featuring a minimalist design, smooth transitions, and a focus on high-end beauty retail.

---

## ✨ Key Features
* **Premium Catalog:** Elegant display of hair oil products with high-resolution imagery.
* **Product Details:** In-depth information about ingredients, benefits, and usage instructions.
* **Smart Shopping Cart:** Easy-to-use cart management for a frictionless checkout process.
* **Advanced Filtering:** Quickly find oils based on hair type or specific hair concerns.
* **Modern UI/UX:** Clean, intuitive, and highly responsive interface designed for beauty enthusiasts.
* **Theme Support:** Fully optimized for both Light and Dark modes.

## 🛠 Tech Stack
* **Framework:** [Flutter](https://flutter.dev)
* **Language:** [Dart](https://dart.dev)
* **State Management:** (e.g., Provider / BLoC / GetX)
* **Database:** (e.g., Firebase / Supabase)
* **Design Pattern:** Clean Architecture
